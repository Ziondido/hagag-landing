# קבוצת חגג — דף נחיתה ✦

דף נחיתה מודרני (RTL, עברית) לקבוצת חגג. מבקרים יכולים:

- ✍️ **להשאיר ביקורת טקסט** עם דירוג כוכבים
- 🎥 **להקליט המלצת וידאו** — **בהסכמה מלאה ושקופה**

עיצוב: רקע aurora מונפש, glassmorphism, גרדיאנטים, רספונסיבי מלא.

---

## 🔒 פרטיות והסכמה (חשוב)

פיצ'ר הווידאו **שקוף לחלוטין** — לא חשאי:

1. המבקר חייב לסמן תיבת הסכמה לפני שהמצלמה נפתחת.
2. הדפדפן עצמו מבקש הרשאת מצלמה/מיקרופון ומציג חיווי הקלטה.
3. המבקר רואה **תצוגה מקדימה חיה** של עצמו.
4. ההקלטה מתחילה רק בלחיצה מפורשת על "התחל הקלטה".
5. שום דבר **לא נשלח** עד לחיצה על "שלח לקבוצת חגג".
6. אפשר לצפות, להקליט מחדש, או להוריד עותק לפני שליחה.

איסוף וידאו של אנשים ללא ידיעתם והסכמתם אינו חוקי ואינו נתמך בפרויקט הזה.

## הרצה מקומית

האתר עצמו **סטטי** — מספיק לפתוח `index.html`, או:

```bash
# הגשת קבצים סטטיים (כל שרת סטטי מתאים)
python3 -m http.server 8080
# פתח http://localhost:8080
```

> הערה: גישה למצלמה דורשת `https://` או `localhost`. ב-GitHub Pages זה עובד (HTTPS).

### שרת קליטה אופציונלי (לשמירת ביקורות + וידאו)

```bash
node server.js          # רץ על http://localhost:3000, ללא תלויות חיצוניות
```

ואז ב-`config.js` הגדר:

```js
window.HAGAG_CONFIG = { UPLOAD_ENDPOINT: "http://localhost:3000" };
```

- ביקורות נשמרות ב-`uploads/reviews.json`
- סרטונים נשמרים ב-`uploads/videos/`

**מצב מקומי (ברירת מחדל, `UPLOAD_ENDPOINT: ""`):** ביקורות נשמרות ב-`localStorage` של הדפדפן, וסרטוני וידאו ניתנים להורדה כקובץ במקום שליחה.
